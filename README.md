# Computer Vision Research Project

This repository contains the literature review, M2 baseline reproduction, and M3 research design for patient-level evaluation of malaria parasite classification.

## Structure

- `data/`: source data and mapping files
- `src/`: baseline implementation
- `notebooks/`: reproduction notebook
- `results/baseline/`: measured baseline artifacts
- `papers/`: literature summaries
- `milestones/`: milestone documents and status
- `presentation/`: slides, scripts, and updates
- `reports/`: submitted literature-review report
- `docs/`: project and runtime documentation

M1, M2, and M3 are complete. M4 is not started; its plan is recorded only in the M3 experiment-design document. M5 is not started.
